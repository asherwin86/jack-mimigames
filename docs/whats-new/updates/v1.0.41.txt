Search engine setup for the website
-----------------------------------
The website now has what search engines need to find and list it: a proper page title and description, share previews (picture and text when the link is posted in chats and social apps), a sitemap.xml, a robots.txt, a canonical address, and structured data that lists all 100 games with their descriptions.
The game list is also written into the page for crawlers that do not run JavaScript, and it is rebuilt automatically from the game list every release.
No change to how anything plays.
