Controller Start opens the pause screen (all games)
---------------------------------------------------
- Start on a controller now opens the pause screen in every game, including
  Blockcraft, and presses again to close it. (Kart Circuit keeps its own pause
  on the same button - checked, it works through the controller bridge.)
- Start does nothing on the "ready?" card before a game begins and after the
  results appear, so it can't kick you out by accident.
- Android app: controllers that send Start as a "Menu" key are handled too.
