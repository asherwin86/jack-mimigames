School holiday colours now flash through the whole palette
----------------------------------------------------------
During the school holidays the menu background is now one flat colour at a time that flashes through every colour in the arcade's palette (cyan, pink, lime, amber, violet, blue and red), in a new random order each time the menu opens.
It changes once a second with a quick fade, so it is lively but not a strobe. The "Holiday colours" switch in Settings turns it off, and "Black sky" still overrides it.
Only the menu changes. Add ?season=holidays to the address to preview it on any day.
